Model Context Protocol (MCP) Architecture

                
Understanding how MCP Server Mode and MCP Host Mode work together

              

            

          

          

            

              

                
🟢 MCP Server Mode

                
Provider / Tool Exposer

                
Exposes functions and data as standardized tools via the Model Context Protocol.

                
    
                  
  • Standard: tools/list, tools/call
    • 
                  
  • STDIO Mode: python server.py --mcp connects Cursor IDE or external MCP Host clients directly to your agents.
    • 
                  
  • Web Mode: Provides web UI while exposing 10 agent tools in-memory.
    • 
                

              

              

                
🟣 MCP Host Mode

                
Consumer / Tool Invoker

                
Acts as the AI Application client that queries MCP servers, binds to tools, and executes them.

                
    
                  
  • Discovery: Dynamically loads tool manifests and parameters.
    • 
                  
  • Execution: Encapsulates payloads into standard JSON-RPC 2.0 frames.
    • 
                  
  • Autonomous: Chat assistant matches user intent directly to tool calls.
    • 
                

              

            


            

              
Protocol Interaction Flow

              
+-------------------------------------------------------------------------------+
|                             MCP HOST (Client)                                 |
|  - Reads user intent or UI form inputs                                        |
|  - Packages request: {"jsonrpc": "2.0", "method": "tools/call", ...}          |
+---------------------------------------+---------------------------------------+
                                        |  HTTP POST / stdio stream
                                        v
+-------------------------------------------------------------------------------+
|                            MCP SERVER (Provider)                              |
|  - Listens for RPC requests                                                   |
|  - Dispatches to Agent 1 (Markdown), Agent 2 (Database), Agent 3 (Docs)       |
|  - Returns formatted JSON-RPC result payload                                  |
+-------------------------------------------------------------------------------+
